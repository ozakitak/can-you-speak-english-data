## Keyword hints and explanation examples

[v4 catalog](v4/catalog.json) provides variable-length keyword cues for all 7,205 records. Unreviewed automatic cues are withheld and displayed as pending review. Only individually authored or sense-rechecked cues are enabled. Explanation examples use individually reviewed overrides where available; all other examples retain the previous prose and are not marked rechecked. See [hint and example audit](research/keyword-hints-audit.json) and [counts](research/keyword-release-report.json). No automatic draft is promoted solely by passing format validation. Existing v3 is retained unchanged. Attribution and licenses remain in [CREDITS](CREDITS.md).
